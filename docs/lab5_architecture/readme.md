# Лабораторная работа № 5. Архитектура системы (диаграммы)

**Цель:** разработать архитектуру TaskTracker и изобразить её стандартными UML-диаграммами. Инструмент: Rational Rose / Ramus / любой другой (в простейшем варианте — Draw.io). Окончательные артефакты закрепляются в GitHub.

## Диаграммы (в папке `docs/lab5_architecture/`, формат PlantUML)
1. **use_case.puml** — диаграма вариантов использования (Use Case): регистрация/вход, создание, просмотр, редактирование, удаление задач, отметка выполнения, фильтрация.
2. **sequence.puml** — диаграмма последовательности (взаимодействия): пользователь → интерфейс → контроллер → хранилище для сценариев просмотра, создания, завершения и удаления задачи.
3. **state.puml** — диаграмма состояний задачи: Новая → Активная → Выполнена → Удалена.
4. **class.puml** — диаграмма классов: Task, TaskController, TaskRepository, UserInterface, FlaskApp со связями.
5. **deployment.puml** — диаграмма развёртывания: браузер пользователя, сервер Flask, GitHub (репозиторий + Actions + Wiki), ПК разработчика.

## Как открыть
- Файлы `.puml` открываются в любом редакторе PlantUML (плагины для VS Code, IntelliJ, Draw.io, онлайн-сервер plantuml.com).
- Для вставки в отчёт диаграммы можно экспортировать в PNG через PlantUML или перерисовать в Draw.io.

## Содержание диаграмм (кратко)
- **Use Case:** 7 вариантов использования, все инициируются актёром «Пользователь».
- **Sequence:** 4 сценария (просмотр, создание, завершение, удаление задачи).
- **State:** 4 состояния задачи.
- **Class:** 5 классов с атрибутами и методами, ассоциации TaskController–Task–TaskRepository, UserInterface–TaskController, FlaskApp–TaskController.
- **Deployment:** 4 узла (браузер, сервер, GitHub, ПК разработчика).
