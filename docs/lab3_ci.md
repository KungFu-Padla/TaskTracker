# Лабораторная работа № 3. GitHub Actions (непрерывная интеграция)

**Цель:** познакомиться с автоматизацией тестирования через вкладку **Actions** в GitHub на простом примере (деление на ноль, чёт/нечёт), а затем запустить простейшие тесты своего проекта.

## Инструменты
- GitHub (вкладка Actions)
- GitHub Actions (YAML-воркфлоу `.github/workflows/ci.yml`)
- pytest (Python)

## Шаг 1. Простые тесты (примеры)
Создан файл `tests/test_simple.py` с тестами:
- `test_division_by_zero_raises` — деление на ноль вызывает `ZeroDivisionError`;
- `test_safe_divide_normal` — корректное деление;
- `test_even_numbers` / `test_odd_numbers` — чётность/нечётность.

## Шаг 2. Настройка GitHub Actions
Создан файл `.github/workflows/ci.yml`. Воркфлоу срабатывает при:
- `push` в ветки `main` и `develop`;
- `pull_request` в эти ветки.

Шаги воркфлоу:
1. `actions/checkout@v4` — выкачивает код репозитория;
2. `actions/setup-python@v5` — устанавливает Python 3.11;
3. Установка зависимостей (`pip install -r requirements.txt`);
4. Запуск тестов (`pytest`).

## Шаг 3. Запуск и проверка
1. Запушить изменения в репозиторий на GitHub.
2. Перейти во вкладку **Actions** репозитория.
3. Убедиться, что воркфол «CI» запустился и все тесты прошли (зеленая галочка).
4. При падении любого теста — воркфлоу помечается красным, ошибка выводится в логе.

## Тесты проекта (на сдачу 2–3 штуки)
В файле `tests/test_app.py` реализованы тесты прототипа TaskTracker:
- `test_create_task` — создание задачи (POST /tasks) возвращает 201 и корректные поля;
- `test_complete_task` — пометка задачи выполненной (POST /tasks/<id>/complete) меняет `done` на True.

Все тесты запускаются локально:
```
pytest
```
и автоматически при каждом пуше через GitHub Actions.

## Итоговые артефакты
- `.github/workflows/ci.yml` — конфигурация CI;
- `tests/test_simple.py` — простые тесты (деление на ноль, чёт/нечёт);
- `tests/test_app.py` — 2 теста проекта;
- Успешный прогон воркфлоу на GitHub (скриншот вкладки Actions вставляется в отчёт).
