# Лабораторная работа № 6. Проектирование интерфейсов (Figma)

**Цель:** спроектировать интерфейс системы TaskTracker в Figma. Окончательный релиз закрепляется в GitHub (например, через ссылку в Wiki).

## Примечание
Поскольку прямой доступ к аккаунту Figma отсутствует, макеты интерфейса представлены в виде HTML-прототипов (4 экрана) в папке `docs/lab6_figma/`. Они точно соответствуют техническому заданию и могут быть перенесены в Figma при наличии доступа.

## Макеты (экраны)

### Экран 1. Страница входа / регистрации (Login / Sign Up)
- Файл: `screen1_login.html`
- Поля: «Email», «Пароль», «Повторите пароль» (только для регистрации).
- Кнопки: «Войти», «Создать аккаунт».
- Ссылка: «Забыли пароль?».

### Экран 2. Главная — список задач (Task List)
- Файл: `screen2_task_list.html`
- Заголовок: «Мои задачи».
- Кнопка «+ Добавить задачу».
- Фильтры: «Все» / «Активные» / «Выполненные».
- Список карточек задач: чекбокс «Выполнено», название, дата создания, кнопки «Редактировать» и «Удалить».
- Пустое состояние.

### Экран 3. Создание / редактирование задачи (Task Form)
- Файл: `screen3_task_form.html`
- Поле «Название задачи» (обязательное).
- Поле «Описание» (необязательное).
- Кнопки: «Сохранить», «Отмена».

### Экран 4. Карточка задачи (модальное окно при клике)
- Файл: `screen4_task_card.html`
- Название, описание, статус, дата создания/обновления.
- Кнопки: «Завершить», «Редактировать», «Удалить», «Закрыть».

## Элементы дизайна (система компонентов)
- Цвет акцента: синий (#3B82F6) для основных действий.
- Цвет успеха: зелёный (#10B981) для выполнённых задач.
- Цвет опасности: красный (#EF4444) для удаления.
- Шрифт: Inter / Roboto, размер основного текста 14–16 px.
- Отступы: сетка 8 px.

## Как открыть
Откройте любой HTML-файл в браузере (например, `screen2_task_list.html`). Все стили находятся внутри файла (инлайн CSS), дополнительная установка не требуется.

## Связь с GitHub Wiki
Публичную ссылку на Figma (или на эту папку с HTML-макетами в репозитории) необходимо вставить на страницу **Home** в GitHub Wiki (см. ЛР 2, подраздел 2.3).
