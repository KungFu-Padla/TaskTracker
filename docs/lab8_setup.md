# Лабораторная работа № 8. Установочный пакет (Setup Creator)

**Цель:** создать установочный пакет для проекта TaskTracker и закрепить его в GitHub.

## Инструмент
Любой установщик: Inno Setup, NSIS, Setup Creator, или простой скрипт (bat/powershell). В данном проекте использован скрипт `setup/install.bat` (вариант Setup Creator).

## Содержимое установщика (`setup/install.bat`)
1. Проверка наличия Python в PATH.
2. Копирование файлов приложения в `%USERPROFILE%\TaskTracker\`.
3. Установка зависимостей (`pip install -r requirements.txt`).
4. Создание ярлыка на рабочем столе (`TaskTracker.bat`), запускающего `python app.py`.
5. Сообщение об успешном завершении.

## Пошаговая инструкция по созданию пакета
1. Подготовить папку со всеми файлами проекта (`app.py`, `requirements.txt`, `tests/`, `.github/`).
2. Написать скрипт установки (`install.bat` или файл скрипта Inno Setup `.iss`).
3. Протестировать установщик на чистой системе:
   - запустить установку;
   - проверить, что приложение запускается через ярлык;
   - проверить, что тесты проходят (`pytest`).
4. Запаковать установщик (если используется Inno Setup — скомпилировать `.exe`).
5. Загрузить установочный пакет в репозиторий GitHub (релиз или папка `setup/`).
6. Добавить ссылку на установщик в README и GitHub Wiki.

## Итоговые артефакты
- `setup/install.bat` — скрипт установки.
- (по желанию) скомпилированный `.exe` установщик.
- Инструкция по установке в README.md.
- Размещение пакета в GitHub (релиз / папка setup).
