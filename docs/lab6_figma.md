# Лабораторная работа № 6. Проектирование интерфейсов (Figma)

**Цель:** спроектировать интерфейс системы TaskTracker в Figma. Окончательный релиз закрепляется в GitHub (например, через ссылку в Wiki).

## Макеты (экраны)
Поскольку прямой доступ к аккаунту Figma у меня отсутствует, ниже приведено подробное техническое задание на макеты, по которому можно собрать файл в Figma (или я могу предоставить файл, если будет доступ).

### Экран 1. Страница входа / регистрации (Login / Sign Up)
- Поля: «Email», «Пароль», «Повторите пароль» (только для регистрации).
- Кнопки: «Войти», «Создать аккаунт».
- Ссылка: «Забыли пароль?».

### Экран 2. Главная — список задач (Task List)
- Заголовок: «Мои задачи».
- Кнопка «+ Добавить задачу».
- Фильтры: «Все» / «Активные» / «Выполненные» (вкладки или выпадающий список).
- Список карточек задач, каждая содержит:
  - чекбокс «Выполнено»;
  - название задачи;
  - дата создания;
  - кнопки «Редактировать» и «Удалить».
- Пустое состояние: ilustracija + текст «У вас нет задач».

### Экран 3. Создание / редактирование задачи (Task Form)
- Поле «Название задачи» (обязательное).
- Поле «Описание» (необязательное).
- Кнопки: «Сохранить», «Отмена».

### Экран 4. Карточка задачи (модальное окно при клике)
- Название, описание, статус, дата создания/обновления.
- Кнопки: «Завершить», «Редактировать», «Удалить», «Закрыть».

## Элементы дизайна (система компонентов)
- Цвет акцента: синий (#3B82F6) для основных действий.
- Цвет успеха: зелёный (#10B981) для выполнённых задач.
- Цвет опасности: красный (#EF4444) для удаления.
- Шрифт: Inter или Roboto, размер основного текста 14–16 px.
- Отступы: 8 px сетка.

## Как оформить в Figma
1. Создать новый файл в Figma, назвать «TaskTracker — макеты».
2. Нарисовать 4 экрана выше в рамках (Frames) под размер iPhone / веб 1440 px.
3. Оформить как прототип (связать кнопки перехода между экранами через Prototype).
4. Получить публичную ссылку на файл (Share → Anyone with the link can view).
5. Вставить ссылку в GitHub Wiki (см. ЛР 2, страница Home).
